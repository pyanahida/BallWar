# Ball War

Welcome to **Ball War**, a chaotic, physics-driven arena battle where chaos reigns supreme and only the last ball standing survives.

## Core Gameplay

1. **Set the Stage**: Choose a ball type for Ball A and Ball B. You can toggle them on or off, or set them to the same type to watch a mirror match.
2. **Set the Pace**: Adjust the Speed multiplier (e.g., 1x, 2x, 4x). Higher speeds mean more violent collisions and a much faster match.
3. **Start the Battle**: Click **Start / Reset**. The balls will spawn at random positions with random trajectories and immediately begin moving.
4. **Victory**: The match ends when only one ball remains alive. A victory screen will display the winner.

## The Baseline: The Common Ball

The `Common` ball is your standard baseline. It has a set amount of health, moves at the base speed, bounces off the arena walls, and deals a small amount of damage upon colliding with an enemy. It has no special tricks. 

Use the Common ball as your control group.

## The Unknown (Experiment!)

Beyond the Common ball, the arena hosts a variety of exotic and highly volatile combatants. 

**We will not tell you what they do.** 

Some might shoot. Some might leave things behind. Some might have strange reactions to walls. Some might be entirely immune to damage. The only way to find out is to select one from the dropdown menu, throw it into the arena, and watch the chaos unfold. 

## Controls & Interface

- **Ball A / Ball B**: Select the combatant type using the dropdown, and toggle their presence using the switch.
- **Speed**: Modify the base velocity before starting the match.
- **Pause**: You can pause mid-match to take a breath. From the pause menu, you can either Resume the chaos or Quit to Menu.
- **Start / Reset**: Generates a new match with the current settings.
